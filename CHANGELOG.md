# Changelog

## v0.1 - unreleased

Initial public draft.

- Six levels, L0 through L5, each with permitted actions, human obligations, logging,
  reversibility, and characteristic failure.
- Capability-not-agent framing: autonomy is claimed per capability, never per agent.
- The selection trap: gating the send without gating the target set.
- Blast radius: per capability, per tenant, per platform.
- Reversibility ladder, and the argument that it beats approval.
- Conformance table format plus three tests for whether a level claim is real.
